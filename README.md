# Icy Tower (web build)

Play it here: https://rickben.github.io/icy-tower/

A vertical platform climbing game built with Godot 4.7.2. Steer left and
right while the character jumps automatically, climbing through brick,
sand, and snow areas to reach the summit.

## Controls

- Move: Left/Right arrow keys or A/D.
- Jumping is automatic when landing on a platform; there is no jump button.
- Escape pauses and resumes. M toggles sound.

Falling below the screen places the character back on a safe platform
near the current progress. Reaching the summit shows confetti and a
"You reached the top!" message, with Play Again or Exit options.

This repository contains only the static Godot web export. The playable
game source lives in the `icy_tower` project.
